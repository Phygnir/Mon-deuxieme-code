# L'École des Échecs

Une application gratuite pour apprendre les échecs, en français : leçons, répertoire d'ouvertures, problèmes Lichess classés, parties contre un coach, analyse de tes parties, révision espacée et entraînements de vision.

Tout tient dans `index.html`, sans serveur ni compte. La progression est gardée dans le navigateur, et le bouton « Sauvegarder » (onglet Leçons) l'exporte dans un fichier.

Problèmes : base de puzzles de [Lichess](https://database.lichess.org/#puzzles) (domaine public, CC0). Polices : Bricolage Grotesque, Atkinson Hyperlegible, JetBrains Mono (SIL Open Font License). Pièces : jeu « cburnett » de Colin M. L. Burnett (GPLv2+).
